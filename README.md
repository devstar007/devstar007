## About me

I'm **Jeffrey Herron**, a US-based **AI automation architect and senior full-stack developer**. I build production-ready AI agents, SaaS products, dashboards, automations, and API-connected applications for businesses that need software to do more than look impressive in a demo.

My work spans **product architecture, frontend and backend engineering, LLM integrations, data modeling, and deployment**. I particularly enjoy translating unclear requirements into straightforward user experiences and dependable systems that reduce repetitive work.

> **How I think about engineering:** Start with the business workflow. Choose the simplest reliable architecture. Build for real users. Test the edge cases. Ship, observe, and improve.
